= Installation

== Requirements

* Crystal >= 1.19.0

== As a Library

Add to your `shard.yml`:

[source,yaml]
----
dependencies:
  crystal-asciidoctor-pdf:
    github: aloli-crystal/crystal-asciidoctor-pdf
----

Run `shards install`.

== CLI Binary

[source,bash]
----
git clone https://github.com/aloli-crystal/crystal-asciidoctor-pdf.git
cd crystal-asciidoctor-pdf
shards build --release
sudo cp bin/crystal-asciidoctor-pdf /usr/local/bin/
----

== Dependencies

* https://github.com/aloli-crystal/crystal-asciidoctor[crystal-asciidoctor] (~> 2.0) -- AsciiDoc parser
* https://github.com/aloli-crystal/pdf[pdf] (~> 0.2) -- PDF engine
* https://github.com/aloli-crystal/crystal-rouge[crystal-rouge] (~> 4.7) -- syntax highlighting
