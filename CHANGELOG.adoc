== v2.3.24.4 — 2026-04-23

Real country flags in table cells, via a new SVG rendering pipeline.

* **New dependency** `crystal-flags` (~> 0.1) — 271 ISO 3166-1 alpha-2
  SVG flags from lipis/flag-icons embedded at compile time.
* **Inline flag rendering in table cells**: pairs of Unicode regional
  indicator characters (e.g. `🇫🇷`, `🇩🇪`) are detected in cell text
  and drawn as actual colour SVG glyphs on top of the text layer, at
  the baseline of the surrounding text. Previously those codepoints
  rendered as tofu boxes (DejaVu Sans has no glyph for them) and
  threw off the cell width calculation.
* **Layout**: `text_width` and `wrap_text` now charge each flag as a
  fixed width derived from the font size, so columns reserve the
  correct amount of space instead of counting the `.notdef` width
  from the text font.
* **Dependency bump**: `crystal-pdf` → `~> 0.3` (uses the path-parser
  loop fix and the closed-shape fill fix shipped in crystal-pdf
  v0.3.1 and v0.3.2).
* New helper module `AsciidoctorPDF::InlineFlags` with `segments`,
  `flag_width` and `flag_height`.

== v2.3.24.3 — 2026-04-23

Layout and typography fixes observed on real-world documents.

* **Admonitions** (NOTE, TIP, IMPORTANT, WARNING, CAUTION): the label
  now has a proper gap before the text. Previously the label fit in a
  fixed 60 pt slot regardless of its rendered width, which made long
  labels like `IMPORTANT` visually collide with the first word of
  the message.
* **Section titles**: long titles are now wrapped across multiple
  lines instead of being rendered past the right margin (and
  truncated). Uses the existing `wrap_text` helper with the heading
  font.
* **Table cells**: words that do not fit in their column (typical
  for country names in narrow proportional columns, e.g. `Allemagne`
  or `Pays-Bas`) are now broken into sub-chunks. Break priority:
  internal hyphens (`Pays-` + `Bas`), camelCase boundaries, then a
  per-character fallback. No visual overflow into the neighbouring
  column any more.
* **Default body font size**: lowered from 10.5 pt to 10 pt. Mostly
  cosmetic — makes dense tables fit better on A4 without changing
  the heading hierarchy.

== v2.3.24.1 — 2026-04-22

* Project restructured to produce a proper native binary. The CLI source
  script moved from `bin/crystal-asciidoctor-pdf` to `src/cli.cr`;
  running `shards build --release crystal-asciidoctor-pdf` now produces
  an ELF/Mach-O binary at `bin/crystal-asciidoctor-pdf` without
  overwriting any source file, making the tool directly usable after
  `shards build`.
* Tighten `.gitignore`: drop the `/crystal-asciidoctor-pdf-bin`
  workaround and simply ignore `/bin/*`.
* Add the *ameba* linter to the CI pipeline with the shared
  `.ameba.yml` config aligned with the Crystal ecosystem.
* Add a bilingual changelog (CHANGELOG.adoc in English,
  CHANGELOG.fr.adoc in French); remove a leftover CHANGELOG.md.
* Reformat `inline_renderer.cr`, `theme.cr`, `theme_loader.cr` via
  `crystal tool format`.
